## Activation rules

The restructuring is ungated, as the feature owner decided on 2026-10-20. Each of its tasks is live when merged and must keep behavior parity apart from the G2 and G8 fixes. The capability-gated groups merge with their `Policy` fields false. The last task of each gated group wires those fields to `VMNetworkHotPlug` (T011).

| Delivery group | Tasks | Gating | Activates |
|---|---|---|---|
| Restructuring | T011–T019 | Ungated | Nothing user-visible; parity only. T011 only adds the capability key. |
| Partial readiness | T020–T022 | Ungated | Pending interfaces stop blocking shutdown and independent config; explicit power-on gate; shared identity everywhere; cleanup with UID preconditions. |
| Per-interface status | T023–T025 | `InterfaceStatus` | Spec-first status entries and per-interface conditions. Requires T002. |
| Powered-off attachment replacement | T026–T029 | `EditAttachments`, `ChangeVersion` | Edit in place, pending-replacement disconnect, provider handoff, guest invalidation. Requires T004, T005, T007, T008, T009. T026's VPC-restore and fail-over folding is ungated. |
| Bootstrap rule | T032 | `NICsOutOfGOSCHash` | G15: interface changes no longer re-customize LinuxPrep/Sysprep. Requires T003. |
| Live changes | T031, T033 | `LiveChanges` | Hot add/remove, then live edits. Requires the replacement group and the bootstrap rule. |
| Adapter types | T037 | `AdapterTypes` | Explicit-type create/add and same-unit Remove+Add on type mismatch. Requires validated R14 pairs and the live/replacement/bootstrap groups. |

T030 (escape hatch) is optional and independent once T026 has merged. T037 was appended without renumbering existing tasks and executes before final validation. T034 validates AC1–AC25.
